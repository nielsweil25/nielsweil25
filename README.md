## Featured Project

### Avellaneda–Stoikov Market-Making Model

Python implementation of an inventory-based market-making model, including:

* simulation of an arithmetic Brownian mid-price;
* inventory-dependent reservation prices;
* optimal bid and ask quotes;
* stochastic order executions;
* inventory and P&L visualisation.

[View the project](https://github.com/nielsweil25/Avellaneda-Stoikov-Model)

## Other Projects

### Value at Risk Modelling

Implementation and comparison of three Value at Risk methods on a multi-asset portfolio:

* Historical VaR
* Parametric VaR using the variance-covariance method
* Monte Carlo VaR

The project estimates potential portfolio losses at 95% and 99% confidence levels and highlights the assumptions and limitations of each method.
[View the project](https://github.com/nielsweil25/3-Value-At-Risk-Comparison-on-the-Same-Portfolio)

### Portfolio Optimisation

Construction of a Markowitz efficient frontier to identify optimal portfolio allocations and compare their risk-adjusted performance with the S&P 500.

### Financial Modelling and Equity Research
